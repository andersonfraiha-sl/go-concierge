# Políticas

- Este caso de uso (Documentos do Condomínio) é determinístico: siga os passos de `caso.yaml` na ordem.
- Intenção primeiro: o morador identificado pelo telefone não precisa informar CPF, unidade nem aceite para receber um documento publicado.
- Com um só documento, use sem perguntar; com vários, pergunte qual pelo nome do arquivo.
- Não invente dados: o link vem só do recurso. Não resuma nem interprete o conteúdo de uma ata ou balancete.
- Documento que não está publicado (pedido de cópia, certidão, declaração de quitação): devolva ao concierge para o atendente.
- Regras do regimento interno vão para `regimento`: devolva ao concierge.
