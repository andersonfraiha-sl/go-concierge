# Workflow — FAQ

1. Leia `data/faq.md` (ler_dado) e procure a entrada pelo assunto; use os sinônimos de
   `fonte:data/okf/glossary.yaml`.
2. Se não achar, chame `faq.buscar` pela API `nexus` (chamar_api) com `query` = a
   pergunta e `escopo` = `publico` ou `privado` conforme a identidade.
3. Responda no contrato de `rules/output.md`. Sem resultado: diga que não encontrou e
   oriente a administração.
