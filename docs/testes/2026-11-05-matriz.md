# Matriz de classificação — go-concierge

Contexto do produto usado para julgar cada item: concierge de condomínio em Go, roda local
via `docker-compose`/`build.sh --run`; Studio React 19 embutido; integra com Gruvi, Atende,
MCP (catálogo Gruvi) e Nexus da Superlógica; **sem app mobile, sem pagamentos, sem e-mail
próprio, sem filas externas próprias**; deploy em produção ainda não definido (sem
ambiente real, sem réplicas, sem canary pipeline). Repo tem: `internal/falha` (circuit
breaker/retry, `go-retry`), `internal/ganchos` (regra de segurança em código + auditoria),
`internal/banco` com testcontainers Postgres, `bateria/` (harness próprio de eval
conversacional com LLM real via token de dev já configurado), Studio com Vitest +
Testing Library (sem Playwright/axe instalados ainda, mas a frente de Studio os adiciona
localmente), CI com gofmt/vet/golangci-lint/govulncheck/gitleaks/`go test -race`.

Legenda de status:
- **frente**: uma das 5 frentes automatizadas locais cobre (back Go · API/segurança ·
  Studio UI/E2E/acessibilidade/visual · desempenho/resiliência · conversa/IA determinística).
- **plano**: aplica-se, mas exige pessoas, produção ou ambiente que não existe localmente.
- **na**: não se aplica ao produto, com motivo concreto.
